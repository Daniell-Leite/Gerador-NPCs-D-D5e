# Gerador-NPCs-D&D5e
    
Um programa para gerar tabelas aleatórias de NPCs, definindo atributos úteis para o sistema (inicialmente D&D 5e, com planos de deixá-lo mais customizável depois), incluindo voz, aparência, raça, maneirismos (comportamentos únicos), segredos e motivação. Será feito em Python e futuramente irá para a web
